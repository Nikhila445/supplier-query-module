Why it's built this way

  1. One flow, three stops. Supplier → query → status mirrors how a QA manager already thinks about the job, so nothing needs explaining.
  2. Status is a seal, not a word. Colour + shape (like a certificate stamp) means status is readable at a glance across a long list, and never relies on colour alone — each seal has a label and an icon.
  3. The form asks for less, not more. Only 3 required fields; everything else is optional or pre-filled, so raising a query takes under a minute.
